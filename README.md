# selenium-saucedemo

UI test automation project using [Selenium](https://www.selenium.dev/) with Java to test the [Sauce Demo](https://www.saucedemo.com/) web application from Sauce Labs.

## Prerequisites

![Java](https://img.shields.io/badge/Java-orange?logo=openjdk)
![Maven](https://img.shields.io/badge/Maven-C71A36?logo=apachemaven)

## Setup

```bash
#Clone the repository:
git clone https://github.com/joaquinpiedracueva/selenium-saucedemo.git
```
